# 将Qt的UI植入到CAA的Dialog里面

我们都知道CAA自带的对话框设计界面很简陋，想实现很多复杂精致一点的界面就几乎做不到；但是Qt几乎完美补全了这些缺点，于是就有一个想法把Qt的UI界面植入到CAA的对话框中。

## 版本对照

这里有个前置环境条件，如果你是3DE开发的话，应该是自带的有一个Qt5Plugins文件夹的，如果是高版本可能会是Qt6，你先点开里面任意一个dll文件的属性，来到详细信息查看产品版本或者文件版本是多少（我这里是5.9.0.0），然后到Qt官网下载对应的Qt安装，编译器应该和你的VS版本一致（2015，2017....），在下载完成之后，最基本的环境配置已经成功了。（这里我在参照别人的教程寻找qt版本的时候踩过很多坑，比如3DE原本自带有qmainwindow.dll，Qt版本一直不对导致无法初始化QApplication等等）。

## 文件结构

最开始我是将CAA和Qt的文件放到同一个module下的，这样虽然也能成功，但是如果你要封装Qt，让其它的module也能使用该Qt UI的话，就得分开来包装。

Qt中的所有头文件我都放在了publicinterfaces里面，不然会出现找不到头文件的情况。

## 寻找链接Qt环境

在imakefile里面新加了LOCAL_LDFLAGS，里面第一个lib文件是编译qt_src之后产生的文件，路径在build_qt.bat有写，默认是在同module目录下的Object/win_b64下面；下一个libpath是后面三个Qt5 lib文件的路径，这个是你安装Qt编译器的里面有的，一般是xx\xx\msvc2015_64\bin，user32.lib是系统文件。

bridge文件里面也有addLibraryPath添加了3DE的plugin文件夹位置，我在使用Codex的时候他告诉我可以不用添加，3DE会自己去寻找到该路径，但是我尝试注释掉之后就会报错，所以我也不清楚这些是否必要，但是我还是加了上去。

同时我传入了一个json文件作为我测试树表的数据集，我认为这里的封装不是很妥当，但是由于我自己的造诣不够深入我也不知道如何去修改封装（如果要去修改估计会花一点时间，我没那么多精力了），所以就将就着使用了。



最后，这个Qt文件和CAA的文件都是可以自由调整的，这里只是提供一种做法和思路，欢迎纠错和探究。
